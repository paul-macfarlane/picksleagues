# Epic: Foundation (FND)

Monorepo scaffold, environments, auth, the Clock service, the OpenAPI contract pipeline, and CI — the structural bets from `docs/architecture.md` (§Stack, §Environments, §Simulator & Time, §Automated Testing, §Monorepo Layout) that are cheap on day one and expensive later.

- [x] **FND-1** — pnpm workspaces monorepo scaffold per arch §Monorepo Layout: `apps/web` (Vite + React + TanStack Router/Query + Tailwind + shadcn/ui), `apps/api` (Hono + `@hono/zod-openapi` on Vercel Functions), `packages/schemas`, `packages/db`, `packages/core`, `packages/scoring`, `openapi/`; shared tsconfig, ESLint, Prettier; typecheck/lint/test scripts wired at the root. _(deps: none)_
- [x] **FND-2** — Local Docker Postgres (compose file matching Neon major version) + Drizzle in `packages/db`: drizzle-kit config, migration workflow, `db:up`/`db:migrate` scripts. _(deps: FND-1)_
- [x] **FND-3** — Typed env validation (zod, validated once at startup) incl. `APP_ENV` (`local`|`staging`|`production`) + `.env.example` covering all vars. Arch §Environments. _(deps: FND-1)_
- [x] **FND-4** — Better Auth: Google + Discord OAuth, Drizzle adapter, cookie sessions; `users` extended with citext-unique `username` + `display_name` per spec §Users & Identity. _(deps: FND-2)_
- [x] **FND-5** — OpenAPI pipeline: spec generated from the Hono routes and committed to `openapi/`; `openapi-typescript` + `openapi-fetch` client generation for the SPA; a drift-check script (regenerate + fail if dirty). Arch D4. _(deps: FND-1)_
- [x] **FND-6** — `Clock` service in `packages/core` (system time in prod; DB-persisted offset via `app_state` in non-prod) + lint rule banning raw `Date.now()`/`new Date()`-as-now/SQL `now()` in domain logic. Arch §Simulator & Time, D13. _(deps: FND-2)_
- [x] **FND-7** — Test harness: Vitest (unit + in-process Hono integration against Docker Postgres) + Playwright e2e; `test`/`test:e2e` scripts, CI-ready Postgres service config, one smoke test per layer. Update `.claude/skills/verify/SKILL.md` with the real launch/drive recipe. Arch §Automated Testing, D14. _(deps: FND-2)_
- [x] **FND-8** — CI (GitHub Actions) on every PR: typecheck, lint (incl. the FND-6 rule), unit, integration, e2e, OpenAPI drift check; green CI required to merge to `staging`; promotion `staging`→`main` re-runs the suite. _(deps: FND-5, FND-6, FND-7)_
- [~] **FND-9** — _(runbook written; console provisioning blocked on human — see docs/runbooks/environments.md)_ Environments: Vercel project (`main`→Production, fixed-alias `staging` branch deploy), Neon `staging` branch + primary, per-env Google/Discord OAuth apps with registered redirect URIs, per-scope env vars. - [x] **FND-10** — Safety hook prompting on destructive commands (`git push` to staging/main, Vercel prod deploys, drizzle-kit against non-local DB, job/sim calls against non-local hosts). Done as harness setup: `.claude/hooks/guard-destructive.sh` + `PreToolUse` in `.claude/settings.json`. _(deps: none)_
