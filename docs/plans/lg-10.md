## Intent

Commissioner surfaces whose spec window (§Commissioner Powers) has closed
currently render enabled and fail only on save with the server's 409
(`league_started`). The fix makes each window-closed control render disabled
with an inline reason, computed from the **server's** clock (`useAppNow()`)
against the wire's `startsAt` — which is exactly why `canActOnLeague`
(`apps/web/src/lib/league.ts`) was allowed to hardcode `preStart: true` until
now. The server's refusal remains the enforcement; the disable is a hint plus
an explanation. No API, schema, or contract change.

## Facts the plan rests on (surveyed 2026-08-06)

- `LeagueResponse.startsAt` (`packages/schemas/src/leagues.ts`) is the
  clock-derived league start, **null while not derivable — and null means
  pre-start** (schema comment).
- Server boundary (`apps/api/src/services/leagues/start.ts`): `isPreStart` =
  `startsAt === null || clock.now() < startsAt`. So **started ⇔
  `startsAt !== null && now >= startsAt`** — the client mirror must use `>=`,
  not `>`.
- The action matrix (`packages/schemas/src/league-actions.ts`) already exposes
  both axes separately (`leagueActionRequiresCommissioner`,
  `leagueActionIsPreStartOnly`). Window-carrying actions: `EDIT_VISIBILITY`,
  `EDIT_SETTINGS`, `DELETE_LEAGUE`, `KICK_MEMBER`, `LEAVE_LEAGUE`. Anytime:
  `EDIT_NAME`, `PROMOTE_MEMBER`, `DEMOTE_COMMISSIONER`, `MANAGE_INVITES`,
  `RENEW_SEASON`.
- Server PATCH mapping (`apps/api/src/services/leagues/crud.ts`): one PATCH
  carries field-level actions; **name is the lone anytime edit; `maxMembers`
  rides `EDIT_SETTINGS`**. A post-start PATCH carrying any pre-start-only field
  409s whole; a name-only PATCH succeeds post-start. The SPA already sends only
  dirty fields, so disabling the lockable fields makes post-start saves
  name-only by construction.
- `canActOnLeague` call sites: `settings.tsx` (`EDIT_SETTINGS` → `canEdit`,
  `DELETE_LEAGUE` → renders DangerZone), `members.tsx` (`KICK_MEMBER` →
  `isCommissioner` prop that also gates promote/demote, `MANAGE_INVITES` →
  renders InvitePanel), `index.tsx` (`RENEW_SEASON`).
- `useAppNow()` (`apps/web/src/lib/app-clock.ts`) is minute-truncated and
  re-renders subscribers each minute — a page left open flips its controls
  live when the window closes, at up to ~59 s of hint lag around the boundary.
  The 409 → error toast path already in place covers that sliver.
- `league-header.tsx` carries no mutation controls; nothing to gate there.
- E2E (`e2e/league-lifecycle.spec.ts`) has no post-start coverage today.

## Decisions resolved into the plan

1. **Role gates hide; window gates disable-with-reason.** A member who lacks
   the role keeps seeing nothing (or read-only, for settings) — unchanged. A
   commissioner whose window closed sees the control disabled with an inline
   reason: they *had* the power, and the explanation is the ticket's point.
2. **One home for the window derivation.** `leagueHasStarted(league, now)` in
   `apps/web/src/lib/league.ts`, mirroring the server's `isPreStart` boundary
   (null-safe, `>=`). `canActOnLeague(league, action, now)` gains the `now`
   parameter and passes `preStart: !leagueHasStarted(league, now)` — the
   hardcode and its justifying comment go away. Callers read `useAppNow()`
   once per component and pass it down (keeps `lib/league.ts` hook-free).
3. **Settings form splits the name axis.** Post-start a commissioner keeps an
   editable League name (`EDIT_NAME` is anytime); visibility, max members, and
   the per-mode fieldset disable (Base UI `Field.Root`/fieldset `disabled`
   cascade, same mechanism the non-editor read-only gate already uses). The
   existing static expectation copy ("…lock once the league starts") is
   replaced, when started, by the inline reason stating they *are* locked and
   that the name can still be changed. When started, `canSave` considers
   `nameDirty` only — a locked-field edit made in the same minute the window
   closes must not re-enable Save into a guaranteed 409. The pick-summary
   query gates on `isPickem && canEdit && !started` (post-start it feeds a
   warning that can no longer fire).
4. **Danger zone renders for commissioners regardless of window** (role =
   visibility), with the Delete league trigger disabled plus an inline reason
   when started. Route condition in `settings.tsx` changes from
   `canActOnLeague(DELETE_LEAGUE)` (both axes) to the role axis.
5. **Members section:** promote/demote stay enabled post-start (anytime
   actions — the current wiring gates them through `KICK_MEMBER`, which would
   wrongly hide them once the window axis is real; rewire to the role axis).
   Kick triggers disable when started, with **one** inline note in the card
   for commissioners rather than a per-row repeat; each disabled trigger
   points at it via `aria-describedby`. Leave league disables for everyone
   when started, with its own inline reason (membership is frozen).
6. **Anytime surfaces untouched in behavior:** InvitePanel (`MANAGE_INVITES`),
   renew banner (`RENEW_SEASON`) — signature-only updates where
   `canActOnLeague` is called.
7. **Copy is the owner's.** Suggested strings below are placeholders the PR
   review may reword freely; nothing binds to prose — evidence and any
   assertions bind to accessible role/name + `disabled` state (engineering
   rules §Quality, UI tests).
8. **No new e2e spec.** Enablement is presentation policy (rules: "don't
   unit-test presentation policy"; "E2E covers journeys, not branches") and
   the 409 enforcement is already integration-tested server-side. Proof is a
   simulator-driven UI transcript + screenshots. One small **unit** test is
   in scope for `leagueHasStarted` only — that is a domain answer whose `>=`
   boundary and null case must mirror the server, exactly the kind of silent
   drift a table-driven test pins.

Suggested (owner-rewordable) reasons: settings — "Visibility, max members, and
game settings are locked — the league has started. League name can still be
changed."; delete — "Deleting is locked once the league starts."; kick —
"Removing members is locked once the league starts."; leave — "Membership is
frozen once the league starts."
